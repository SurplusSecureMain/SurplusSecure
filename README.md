# Surplus Secure

Michigan tax foreclosure surplus recovery service — helping former property owners recover surplus funds from tax foreclosure sales.

**Led by attorney Kelli Meeks.**

## Tech Stack

- Pure static HTML / CSS / JS (no build step)
- Google Fonts: DM Serif Display + Source Sans 3
- JSON-LD structured data
- Dark mode with system preference detection
- Scroll reveal animations
- Exit-intent popup (mouseleave, scroll-back-to-top, idle fallback)
- FAQ accordion
- Responsive mobile navigation

## Local Preview

Open `index.html` in any browser, or use a local server:

```bash
npx serve .
```

## Deployment

This site is deployed via **Cloudflare Pages**, connected to this GitHub repository. Any push to the main branch triggers an automatic deploy.

- **Dashboard:** [Cloudflare Pages](https://dash.cloudflare.com)
- **Build command:** _(none — static site)_
- **Output directory:** `/`

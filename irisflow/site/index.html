Automations built in

Checklist done → task done. Done → checklist checked. Recurring tasks reschedule themselves. Toggle each per project.

Offline-friendly

Every change saves locally first, then syncs to KV. Lose your connection and keep working; it catches up when you're back.

No lock-in

Your whole workspace is one JSON document in your own Cloudflare account. Export or import it with one click.

Private by design

Passphrase-gated, HMAC-signed sessions, strict security headers, robots blocked. Zero third-party requests — not even fonts.

Deploy in five minutes

git clone https://github.com/SurplusSecureMain/SurplusSecure
cd SurplusSecure/irisflow
npx wrangler kv namespace create IRISFLOW_DATA   # paste id into wrangler.toml
echo 'your-strong-passphrase' | npx wrangler secret put APP_PASSWORD
npx wrangler deploy

That's it — your team's work OS is live at irisflow.<your-subdomain>.workers.dev, on hardware you don't manage, at a price you don't pay.

Frequently asked questions

Is IrisFlow really free?
Yes. It's MIT-licensed open source and runs entirely on Cloudflare's free tier, so hosting costs $0/month for typical small-team usage.
What do I need to run it?
A free Cloudflare account and the wrangler CLI. One KV namespace, one secret, one deploy command. No database server, no build step.
Where does my data live?
In a single JSON document in your own Cloudflare KV namespace. Export the full workspace as JSON any time.
Does it support teams?
Yes — designed for roughly 1 to 15 people behind a shared passphrase, with per-member assignments, comments, and My Tasks. Optimistic revision checks stop two people from silently overwriting each other.
What is the EIM stack?
GitHub for source and history, Cloudflare for hosting and data, and static-first pages hardened with strict security headers and AI-crawler-friendly metadata (llms.txt, JSON-LD, sitemap). It's how Ebony Iris Media ships every site.
